# Credits

## FM26 Access

FM27 Access builds on
[Football Manager 2026 Access](https://github.com/DnDeezNuts/Football-Manager-2026-Access),
created by **DnDeezNuts**. The original developer granted permission to reuse and
adapt the code. FM27 Access continues those accessibility foundations for FM27;
it does not claim exclusive authorship of the inherited work.

The source baseline is FM26 Access 0.2.16, commit
`4d38a0256f29b97376845ef59edfcd64d7f165ed`, from the
[original development repository](https://github.com/DnDeezNuts/FM-26-Access-proof-of-concept).
It supplies the Host/Plugin architecture, navigation and speech libraries,
semantic HTML Companion, panel profiles, interaction contracts, tests and
authored audio cues. Original authors retain their copyright and attribution.

Contributors recorded in the consulted source history include Jacob Shymanski,
Rashad Naqeeb, Zachary Kline, DnDeezNuts, oasis1701 and Leo Guima. This acknowledgment
does not replace the original contribution history or source notices. The
consulted source archive has SHA-256
`F65B1A4477D4702C86B5A9BE1DB7E3B4FF9C80194E2412CFA5EC4A5DDAC6C189`.

respective owners.
