mcs.dll — the Mono C# compiler
==============================

This folder vendors `mcs.dll`, a Unity-targeted build of the Mono C# compiler
(assembly identity: mcs, Version=6.13.0.0). The FM26 Accessibility Mod uses it for
one purpose: the dev driver's POST /eval endpoint, which compiles arbitrary C# against
the live game. It is a development tool and is NOT shipped in the player package.

Provenance
----------
Built from the mcs-unity line of forks, which adapt Mono.CSharp for Unity modding
(backporting the C# 7 compiler to older runtimes, removing the System.XML dependency,
and taking the CoreCLR AssemblyBuilder path that the stock Mono.CSharp NuGet lacks):

  https://github.com/sinai-dev/mcs-unity   (used by UnityExplorer; archived 2023)
  https://github.com/ghorsington/mcs-unity (the upstream of that fork)
  https://github.com/kkdevs/mcs            (source of the C# 7 backport)
